### Сервис рекомендаций

Сервис `recommendations_service.py` предоставляет единый endpoint `/recommendations`, который объединяет онлайн- и офлайн-рекомендации.

Онлайн-рекомендации строятся на основе последних трёх действий пользователя. Для каждого из трёх последних треков сервис получает список похожих треков из `feature_service`. Затем для каждого кандидата рассчитывается итоговый взвешенный score с учётом похожести на все три последних трека. Для первого (самого последнего) трека используется вес 0.50, для второго — 0.33, для третьего — 0.17.

Таким образом, при формировании итогового рейтинга учитывается похожесть кандидата на все три последних трека пользователя, при этом самое последнее действие имеет наибольшее влияние на результат. Если один и тот же кандидат похож сразу на несколько последних треков, его итоговый score формируется как сумма взвешенных значений похожести по этим трекам.


При формировании онлайн-рекомендаций объекты из текущей истории пользователя исключаются, чтобы не рекомендовать уже просмотренные или прослушанные объекты.

Офлайн-рекомендации загружаются из Parquet-файлов. Если для пользователя существуют персональные рекомендации, используются они. Если персональных рекомендаций нет, сервис использует рекомендации по умолчанию на основе популярных объектов.

После получения online- и offline-рекомендаций результаты объединяются в пропорции 70% online и 30% offline. При объединении выполняется дедупликация: один и тот же объект не попадает в итоговый список несколько раз. Если один из источников содержит недостаточно рекомендаций, свободные позиции заполняются рекомендациями из другого источника.

Итоговый список ограничивается параметром `k`.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/Timdevcc/mle-project-sprint-4.git
cd mle-project-sprint-4
```

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

Активировать виртуальное окружение:

```bash
source .venv/bin/activate
```

Установить необходимые зависимости:

```bash
pip install -r requirements.txt
```

### Получение данных

Файлы с рекомендациями:

* `recommendations.parquet`
* `personal_als.parquet`
* `similar.parquet`
* `top_popular.parquet`

можно получить из S3-хранилища по пути:

```text
recsys/recommendations
```
S3-Bucket: s3-student-mle-20260702-1d35328110-freetrack  

Либо скачать исходные данные для построения рекомендаций:

```bash
wget https://storage.yandexcloud.net/mle-data/ym/tracks.parquet
wget https://storage.yandexcloud.net/mle-data/ym/catalog_names.parquet
wget https://storage.yandexcloud.net/mle-data/ym/interactions.parquet
```

После скачивания исходных данных необходимо запустить ноутбук `recommendations.ipynb`, который формирует необходимые файлы с рекомендациями.

### Запуск

Необходимо запустить три сервиса:

```bash
uvicorn event_service:app --host 0.0.0.0 --port 8010
uvicorn feature_service:app --host 0.0.0.0 --port 8020
uvicorn recommendations_service:app --host 0.0.0.0 --port 8000
```

После запуска сервисов тестирование выполняется командой:

```bash
python test_service.py
```

Для сохранения вывода тестирования:

```bash
python test_service.py > test_service.log 2>&1
```

### Тестирование

В `test_service.py` проверяются три сценария:

1. пользователь без персональных рекомендаций — используется offline-рекомендация по умолчанию;
2. пользователь с персональными рекомендациями, но без онлайн-истории — используются персональные offline-рекомендации;
3. пользователь с персональными рекомендациями и онлайн-историей — выполняется смешивание online- и offline-рекомендаций.

Для третьего сценария в event service добавляются следующие треки:

```text
53404
33311009
178529
35505245
24692821
```

Поскольку события сохраняются с помощью `appendleft`, последние три события используются онлайн-рекомендатором с наибольшими весами.
